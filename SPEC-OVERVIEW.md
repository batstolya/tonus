# Tonus — что это и что умеет

**Tonus** — личный хаб здоровья для пользователей Apple Watch. Собирает данные со
всех источников (автоматически через Apple Health и вручную), показывает их в
удобном дашборде, ищет закономерности с помощью статистики и ИИ, напоминает о
препаратах и держит всё в одном месте — в браузере и в Telegram.

Приложение сделано для себя: данные только твои, никакой рекламы, никаких
подписок, работает как PWA на телефоне и десктопе.

---

## Стек

| Слой | Технологии |
|---|---|
| Фронтенд | React + TypeScript + Vite, Recharts, PWA, деплой на Vercel |
| Бэкенд | Supabase: Postgres + Edge Functions (Deno) |
| ИИ | Google Gemini 2.5 Flash — чат, анализ, OCR, отчёты, исследования |
| Автосинк | Health Auto Export → `ingest-health` edge function → Postgres |
| Ручной импорт | Web Worker — Apple Health `export.xml`/`.zip` в браузере |
| Бот | Telegram Bot API через edge-функцию `telegram-bot` (webhook) |
| Планировщик | `pg_cron` → `send-reminders` каждые 5 мин |
| Мониторинг | `claude-monitor/monitor.py` — локальный фоновый сервис (launchd) |

Все данные под RLS (`auth.uid() = user_id`). Ключи Gemini только на сервере.

## Откуда берутся данные

### Автосинк (основной путь)
Приложение **Health Auto Export** на iPhone/Watch шлёт данные по расписанию в
webhook. Edge-функция `ingest-health` пишет их в Postgres в реальном времени —
метрики за день обновляются автоматически без участия пользователя.

Режимы: `shadow` (только в staging, для проверки) → `live` (в боевые таблицы).
Дедуп через unique-констрейнты, несколько источников (iPhone + Watch) не задваивают.

### Ручной импорт (fallback)
Apple Health `export.zip` → Web Worker парсит `export.xml` локально в браузере →
данные заливаются в Postgres. Xiaomi / Mi Band: CSV/zip → `xiaomiParser`.

### Ручной ввод
Быстрый лог в приложении и естественный язык в Telegram: «пил кофе в 14:00»,
«принял финастерид», «съел макдак вечером» — всё сохраняется с датой и временем.

## Что умеет

### Дашборд
- Приветствие и **готовность дня** — составной балл из HRV, пульса покоя и сна
- **Ранний warning** — алерт когда организм под нагрузкой (HRV ниже нормы 3+ дня)
- Карточки ключевых метрик с трендом
- **Заметка дня** — текстовый комментарий, попадает в ИИ-контекст
- ИИ-анализ периода (Gemini объясняет что происходит)
- **Быстрый лог** — кофе/алкоголь/еда/вода/тренировка одним тапом
- **Модель кофеина** — показывает сколько мг кофеина осталось сейчас и к 23:00
- **Индикатор полноты данных** — предупреждает когда в данных пробелы

### Тело (физиология)
- **Обзор** — все метрики с выбором периода, два наложенных графика, таблица
- **Пульс** — avg/покой/макс, оверлеи событий (кофе/алкоголь), HRV тренд
- **Сон** — длительность, фазы (deep/REM/core), время засыпания и пробуждения,
  баровый график по ночам, таблица
- **Активность** — шаги с целями, дистанция, калории, этажи, рекомендации
- **Стресс-карта** — HR-сэмплы по дням ↔ события календаря, нагрузка над базовым

### Дневник (записи пользователя)
- **Препараты** — список активных, запасы (−/+), календарь приёма, напоминания
  через Telegram с кнопками «Принял / +1ч / +2ч / Пропустить»
- **Питание** — дневник еды, калории и БЖУ (ввод текстом → Gemini считает),
  цель по калориям, история, баровый график
- **Анализы** — загрузка PDF или фото → OCR (Gemini) → все биомаркеры с нормами,
  подсветка отклонений 🔴/🟠, тренды по времени
- **Проблемы** — журнал наблюдений по симптомам (акне, одышка и др.),
  выраженность 1–5, фото, график динамики
- **Волосы** — протокол съёмки по ракурсам, оценки (густота/shedding/линия роста),
  сравнение до/после ползунком, тренды, анализ связи с препаратами

### Коуч (ИИ-слой)
- **Инсайты** — авто-карточки трендов (±% за 2 недели), рекорды и серии (🔥),
  дни-выбросы (аномалии), **календарь-хитмап** по любой метрике,
  паттерны по дням недели
- **Исследования** — статистический движок: корреляции Пирсона (метрика↔метрика,
  проблема↔метрика) + эффект событий с лагом (Коэна ≥0.5) → Gemini объясняет
  находки, гипотезы, оговорки; архив прогонов
- **Эксперименты n=1** — активная проверка гипотезы: задаёшь что меняешь и за
  какой метрикой следишь, система считает до/после с размером эффекта (d Коэна)
  и ИИ объясняет результат
- **Цели** — создание цели по метрике, прогресс-кольца, ИИ-рекомендации

### Настройки
- Язык: RU / UK / EN, глобус в шапке → дропдаун
- Telegram: привязка бота, настройка отчётов и вечернего вопроса
- Google Calendar и cal.beskarstaff — синхронизация событий для стресс-карты
- ИИ-расходы: бюджет токенов Gemini, расход по источникам (`/tokens`)
- Автосинк: webhook URL, режим shadow/live, сравнение staging vs prod
- Экспорт данных: полный JSON-бэкап + CSV метрик

### Чат с ИИ
Плавающая кнопка на любом экране. Период 2/4/12 недель. Полный контекст:
сон по ночам с фазами, пульс, активность, SpO₂, события (кофе/алкоголь/стресс),
препараты с историей приёма, анализы, заметки дня, проблемы, волосы.

## Telegram-бот

| Возможность | Описание |
|---|---|
| ИИ-чат | Любое сообщение → вопрос ассистенту с полным контекстом здоровья |
| Естественный ввод | «принял финастерид», «пил кофе в 14:00» → запись в базу |
| Напоминания о препаратах | Пора принять ✅ · +1ч ⏰ · +2ч · Пропустить ⏭ |
| Вечерний вопрос | Бот спрашивает «как прошёл день» → ответ в заметку дня |
| Проактивные алерты | HRV↓>20%, пульс↑>10%, 3 ночи <6ч — раз в день, дедуп |
| Утренняя сводка | Опциональный дайджест утром |
| Двухнедельный отчёт | Авто или по запросу `/report`, настройки приватности |
| `/usage` | Лимиты Claude Code (читает из локального монитора) |
| `/tokens` | Расход Gemini-токенов за месяц по источникам |
| `/status /sync /pause /resume` | Управление синхронизацией и уведомлениями |
| Напоминания о фото волос | Раз в 28 дней если давно не делал фото |
| Напоминания об анализах | Раз в 90 дней если анализы устарели |

## Монитор Claude
`claude-monitor/monitor.py` — фоновый сервис macOS (launchd), опрашивает API
Claude каждые 60с, пишет лимиты в `claude_usage`, шлёт Telegram-алерты при 80%/100%
и при восстановлении. Работает при закрытой крышке ноутбука.

## Статус реализации

### ✅ Готово
Все фазы 1–9 реализованы. Phase 10 реализована на ~80%.

Конкретно работает:
- Автосинк Apple Health (HAE → ingest-health → Postgres, режим live)
- Все экраны приложения (Тело / Дневник / Коуч / Дашборд)
- Telegram-бот полностью: чат, ввод, напоминания, отчёты, нудги, follow-up
- Эксперименты n=1 с Cohen's d и ИИ-объяснением
- Модель кофеина в организме (QuickLog)
- Индикатор полноты данных (DataGaps на дашборде)
- Напоминания о фото волос (28 дней) и устаревших анализах (90 дней)

### ⚠️ Работает частично

**Еда: подсчёт калорий**
- Через **Telegram-бот** — работает полностью:
  - Фото блюда → Gemini vision → название, калории, БЖУ → запись в дневник
  - Текст «съел бигмак и колу» → Gemini оценивает порцию → калории, БЖУ → запись
- Через **веб-интерфейс** — не сделано: NutritionScreen только отображает то,
  что залогировано через бота. Ввод фото/текста с подсчётом AI из веба отсутствует.

**Open Food Facts** — поиск по названию блюда и сканирование штрихкода из веба не реализованы.

**Action loop коуча** — нудг отправляется, follow-up через 2-3 дня есть, но цепочка «принял совет → трекинг → итог» упрощена относительно спеки.

### ❌ Не сделано
- **Данные среды** (погода / световой день / качество воздуха) — нужен выбор API-провайдера (Open-Meteo бесплатный, OpenWeatherMap платный)
- **«Работает ли лечение»** — до/после старта препарата на длинных окнах; нужна `treatments` таблица и UI в разделе препаратов
- **Ввод еды с AI из веба** — фото или текст → калории прямо в NutritionScreen / QuickLog
- **Telegram Mini App** — отложено
