# Tonus — полная спецификация функций

Личный хаб здоровья: импорт данных Apple Watch / Xiaomi, дашборд, аналитика,
ИИ-ассистент, Telegram-бот, отчёты, исследование взаимосвязей. Веб (React+Vite)
+ Supabase (Postgres, Edge Functions на Deno) + Gemini API.

---

## 0. Архитектура

| Слой | Технологии |
|---|---|
| Фронтенд | React + TypeScript + Vite, Recharts, деплой на Vercel (push в `main`) |
| Бэкенд | Supabase: Postgres + Edge Functions (Deno) |
| ИИ | Google Gemini 2.5 Flash (чат, анализ, OCR анализов, отчёты, исследования) |
| Парсинг | Web Worker (`healthParser.worker.ts`) — Apple Health `export.xml` в браузере |
| Бот | Telegram Bot API через edge-функцию `telegram-bot` (webhook) |

Все данные пользователя — под RLS (`auth.uid() = user_id`). ИИ-вызовы идут через
edge-функции (ключ Gemini только на сервере).

---

## 1. Импорт и обработка данных

### 1.1 Источники (онбординг)
- Выбор устройства при первом входе: **Apple Watch** или **Xiaomi / Mi Band**.
- Apple: `export.zip`/`export.xml` → Web Worker парсит локально.
- Xiaomi: `account.xiaomi.com` → CSV/zip → `xiaomiParser`.
- Адаптивная навигация: разделы без данных скрываются (`availableMetrics`).

### 1.2 Метрики (per-day)
ЧСС (avg/min/max), пульс покоя, HRV, пульс при ходьбе, SpO₂, частота дыхания,
температура запястья, VO₂max, сон (длительность + фазы deep/REM/core, время
засыпания/пробуждения), шаги, дистанция, активные калории, минуты тренировки,
этажи. Плюс сырые HR-сэмплы (для карты стресса).

### 1.3 Корректность данных (важные фиксы)
- **Шаги/дистанция/калории**: суммируем в пределах источника, берём максимум по
  источникам (iPhone+Watch не задваиваются).
- **Сон**: длительность = объединение (union) интервалов, не сумма перекрытий;
  фазы — union по каждой; интервалы >16ч отбрасываются как ошибочные.
- **Основной сон**: при фрагментах берём запись с макс. длительностью.
- **Время пробуждения**: единая шкала «часы от полудня» (фикс 09:18≠21:18).
- **SpO₂**: хранится как доля (0.96), везде ×100 → 96%.
- **Дистанция**: в км (не метры).
- **HR-сэмплы**: дедуп по секунде (Apple пишет несколько в секунду).
- **Дубли строк**: unique-констрейнты `metrics_daily (user,date,metric)` и
  `sleep_sessions (user,date)`; фронт берёт максимум при дублях.

## 2. Веб-приложение (экраны)

Навигация в 4 группы: **Дашборд · Тело · Дневник · Коуч** (верх/низ/подменю).

### Дашборд
Приветствие, готовность дня (HRV+пульс+сон), стресс-дни (макс/мин HRV за месяц),
ранний warning (организм под нагрузкой), карточки метрик, заметка дня, ИИ-анализ,
быстрый лог (виджет).

### Тело
- **Обзор (Metrics)** — все показатели, два наложенных графика, таблица.
- **Пульс** — графики avg/покой/макс, оверлеи кофе/алкоголь.
- **Сон** — фазы (бар), время засыпания/пробуждения, таблица.
- **Активность** — шаги с целями, рекомендации, дистанция.
- **Стресс-карта** — события календаря ↔ пульс (нагрузка над базовым).

### Дневник
- **Препараты** — список, запасы (−/+), календарь приёма, **напоминания** (🔔).
- **Анализы** — загрузка PDF/фото → OCR (Gemini), тренды биомаркеров,
  **панель показателей с нормами и подсветкой отклонений** (🔴 высокое / 🟠 низкое).
- **Проблемы** — журнал наблюдений, выраженность 1–5, фото, график динамики.
- **Волосы** — записи по ракурсам, оценки, сравнение, тренды.
- **Быстрый лог** — кофе/алкоголь/еда/вода/лекарства, выбор времени и **даты**.

### Коуч
- **Инсайты** — авто-карточки трендов (±% за 2 недели), рекорды/серии,
  дни-выбросы (аномалии), **календарь-хитмап** (абсолютные нормы), паттерны по
  дням недели.
- **Исследования** — статистический поиск взаимосвязей (Пирсон + эффект событий
  с лагом) → ИИ объясняет; архив прогонов.
- **Цели** — создание целей по метрике, прогресс-кольца, ИИ-рекомендации.

### Настройки
Язык (RU/UK/EN), Telegram, отчёты (частота/подробность/приватность/утренняя
сводка), вечерний вопрос, Google Calendar, cal.beskarstaff, AI-расходы (бюджет),
устройство, **экспорт данных** (JSON-бэкап + CSV метрик).

### Чат с ИИ (виджет на сайте)
Период 2/4/12 недель. Полный контекст: сон с фазами по ночам, пульс, активность,
SpO₂, события (с датами), препараты (с днями приёма), анализы, заметки дня,
проблемы, волосы.

## 3. Telegram-бот

### Команды и меню
`/menu /report /status /sync /pause /resume /usage /tokens` + inline-кнопки.

### Чат с ИИ
Любое сообщение = вопрос ассистенту по данным за 14 дней (тот же полный контекст).

### Естественный ввод
- «принял финастерид 1мг» → отметка на сайте + списание запаса (с датой).
- «пил кофе в 14:00», «съел макдак вечером» → событие в логах.
- Понимает дату/время словами и числом, исправляет опечатки в названиях.

### Напоминания о препаратах (SPEC-REMINDERS)
Расписание на сайте (время, дни недели, тихие часы) → бот шлёт «Пора принять» с
кнопками ✅ Принял · ⏰ +1ч/+2ч · ⏭ Пропустить. Лимит переносов 4ч. Синхрон с сайтом.

### Вечерний вопрос (SPEC-DAILY-NOTE)
В заданное время бот спрашивает «как прошёл день» → ответ сохраняется в заметку
дня → учитывается во всём ИИ-контексте.

### Проактивные алерты
Раз в день ~10:00 (дедуп 3 дня): HRV↓ >20%, пульс покоя↑ >10%, 3 ночи <6ч сна.

### Утренняя сводка (опц.)
Короткое «доброе утро» со сводкой за неделю.

### /usage и /tokens
- `/usage` — лимиты Claude Code (чёрные полоски, читает из `claude_usage`, который
  пишет локальный монитор).
- `/tokens` — расход Gemini-токенов по источникам за месяц.

## 4. ИИ-функции

| Функция | Где | Edge-функция |
|---|---|---|
| Чат-ассистент (сайт) | виджет | `chat-health` |
| Чат-ассистент (бот) | Telegram | `telegram-bot` (Gemini напрямую) |
| ИИ-анализ периода | дашборд | `analyze-health` (через `aiAnalysis`) |
| Двухнедельный отчёт | бот/сайт | `biweekly-report` (детализация, приватность, авто раз в N недель) |
| Рекомендации целей | Цели | `generate-recommendations` |
| OCR анализов | Анализы | `extract-lab` (structured JSON, все маркеры, референсы) |
| Дип-ресёрч взаимосвязей | Исследования | `deep-research` (объясняет посчитанные корреляции) |

Контроль расходов: каждый вызов пишет токены в `ai_usage`; бюджет/расход в Настройках.

## 5. Исследования (статистика + ИИ)

Детерминированный движок (`research.ts`):
- Корреляции Пирсона метрика↔метрика и проблема↔метрика (n≥7, |r|≥0.3).
- Эффект событий (алкоголь/кофе/каждый препарат) на метрики в тот же день и на
  следующий (лаг), порог эффекта Коэна ≥0.5.
Топ-находки → `deep-research` (Gemini объясняет: находки, гипотезы, что проверить,
оговорки). Архив прогонов в `research_runs`.

## 6. База данных (ключевые таблицы)

| Таблица | Назначение |
|---|---|
| `metrics_daily` | дневные метрики (ключ-значение, unique user/date/metric) |
| `sleep_sessions` | сон по дням с фазами (unique user/date) |
| `heart_rate_samples` | сырые HR-сэмплы |
| `intake_events` | быстрый лог (кофе/алкоголь/еда) |
| `supplements`, `supplement_logs` | препараты, приём (+`stock_count`) |
| `reminder_settings`, `reminder_events` | напоминания |
| `lab_files`, `lab_results` | анализы (+`ref_range`, `flag`) |
| `health_concerns`, `concern_logs`, `hair_entries` | проблемы и волосы |
| `context_notes` | заметки дня |
| `chat_sessions`, `chat_messages` | чат |
| `scheduled_reports`, `report_settings` | отчёты (частота/детализация/приватность/утро) |
| `daily_note_settings` | вечерний вопрос |
| `telegram_links`, `telegram_link_tokens` | привязка Telegram (+`tg_session_id`, `awaiting_note_date`) |
| `health_alerts` | дедуп проактивных алертов |
| `research_runs` | архив исследований |
| `ai_usage` | расход токенов |
| `calendar_events` | события для карты стресса |

Планировщик: `pg_cron` дёргает `send-reminders` каждые 5 мин (напоминания,
вечерний вопрос, утренняя сводка, авто-отчёт, алерты).

## 7. Локализация
RU / UK / EN. Подход: обёртка `t("русский текст")` + словарь (`translations.ts`),
русский = ключ. Переключатель-флаг в шапке + в Настройках, автоопределение по
браузеру, сохранение в localStorage.

---

## 8. Монитор лимитов Claude (вне приложения)
Локальный `claude-monitor/monitor.py`: опрашивает API лимитов Claude каждые 60с,
пишет в `claude_usage`, шлёт в Telegram при 80%/100%/восстановлении. Бот по
`/usage` читает из `claude_usage` (Cloudflare блокирует прямой запрос с серверов).
Ограничение: свежие данные только пока монитор запущен (нужен residential IP).
