# Tonus — что это и что умеет

**Tonus** — личный хаб здоровья для пользователей Apple Watch. Собирает данные со
всех источников (автоматически через Apple Health и вручную), показывает их в
удобном дашборде, ищет закономерности с помощью статистики и ИИ, напоминает о
препаратах и держит всё в одном месте — в браузере и в Telegram.

Приложение сделано для себя: данные только твои, никакой рекламы, никаких
подписок, работает как PWA на телефоне и десктопе.

---

## Стек

| Слой | Технологии |
|---|---|
| Фронтенд | React + TypeScript + Vite, Recharts, PWA, деплой на Vercel |
| Бэкенд | Supabase: Postgres + Edge Functions (Deno) |
| ИИ | Google Gemini 2.5 Flash — чат, анализ, OCR, отчёты, исследования |
| Автосинк | Health Auto Export → `ingest-health` edge function → Postgres |
| Среда | Open-Meteo (погода + качество воздуха/пыльца) → `fetch-environment` |
| Ручной импорт | Web Worker — Apple Health `export.xml`/`.zip` в браузере |
| Бот | Telegram Bot API через edge-функцию `telegram-bot` (webhook) |
| Планировщик | `pg_cron` → `send-reminders` каждые 5 мин, `sync-cal` / `coach-weekly` |
| Мониторинг | `claude-monitor/monitor.py` — локальный фоновый сервис (launchd) |

Все данные под RLS (`auth.uid() = user_id`). Ключи Gemini только на сервере.

**Авторизация edge-функций:** функции, вызываемые из UI с user-JWT, имеют
`verify_jwt=true`. Webhook/cron-функции (`ingest-health`, `send-reminders`,
`sync-cal`, `telegram-bot`, `coach-weekly`, `coach-profile`, `register-webhook`)
авторизуются сами (токен/секрет) и держат `verify_jwt=false` — зафиксировано в
`supabase/config.toml`, чтобы флаг не слетал при деплоях (иначе шлюз отбивает их 401).

## Откуда берутся данные

### Автосинк (основной путь)
Приложение **Health Auto Export** на iPhone/Watch шлёт данные по расписанию в
webhook. Edge-функция `ingest-health` пишет их в Postgres в реальном времени.
Режимы: `shadow` (staging, проверка) → `live` (боевые таблицы). Дедуп через
unique-констрейнты; несколько источников (iPhone + Watch) не задваивают.

### Среда (автоматически)
`fetch-environment` тянет из Open-Meteo по локации (Мюнхен): погоду (температура,
давление, осадки, световой день) и качество воздуха (European AQI) + пыльцу.
Кнопка синка в Настройках; данные ложатся в `environment_daily`.

### Ручной импорт (fallback)
Apple Health `export.zip` → Web Worker парсит `export.xml` локально → в Postgres.
Xiaomi / Mi Band: CSV/zip → `xiaomiParser`.

### Ручной ввод
Быстрый лог в приложении и естественный язык в Telegram: «пил кофе в 14:00»,
«принял финастерид», «съел макдак вечером» — с датой и временем. Еда по фото/тексту
→ Gemini считает калории и БЖУ.

## Что умеет

### Дашборд
- Приветствие и **готовность дня** — составной балл из HRV, пульса покоя и сна
- **Ранний warning** — алерт когда организм под нагрузкой (HRV ниже нормы 3+ дня)
- Карточки ключевых метрик с трендом, самый стрессовый/спокойный день периода
- **Заметка дня** — текстовый комментарий, попадает в ИИ-контекст
- ИИ-анализ периода (Gemini объясняет что происходит)
- **Быстрый лог** — кофе/алкоголь/еда/вода/тренировка одним тапом
- **Модель кофеина** — сколько мг кофеина осталось сейчас и к 23:00
- **Индикатор полноты данных** — предупреждает когда в данных пробелы
- **Фокус недели** — цель коуча с отметкой выполнения по дням

### Тело (физиология)
- **Обзор** — все метрики с выбором периода, два наложенных графика, таблица
- **Пульс** — avg/покой/макс, оверлеи событий (кофе/алкоголь), HRV тренд
- **Сон** — длительность, фазы (deep/REM/core), засыпание/пробуждение, бары по ночам
- **Активность** — шаги с целями, дистанция, калории, этажи, рекомендации
- **Стресс-карта** — HR-сэмплы по дням ↔ события календаря, нагрузка над базовым

### Дневник (записи пользователя)
- **Препараты** — активные, запасы (−/+), календарь приёма, напоминания в Telegram;
  **трекинг лечения** — дата старта препарата → сравнение исхода до/после на длинных окнах
- **Питание** — дневник еды, калории и БЖУ; ввод тремя способами: фото блюда (Gemini
  vision), поиск по названию (Open Food Facts), текст; цель по калориям, история
- **Анализы** — PDF/фото → OCR (Gemini) → биомаркеры с нормами, подсветка отклонений
  🔴/🟠, тренды по времени
- **Проблемы** — журнал симптомов (акне, одышка и др.), выраженность 1–5, фото, график
- **Волосы** — протокол съёмки, оценки (густота/shedding/линия роста), сравнение до/после,
  тренды, связь с препаратами

### Коуч (ИИ + статистика)
- **Инсайты** — авто-карточки трендов (±% за 2 недели), рекорды и серии (🔥), аномалии,
  календарь-хитмап по метрике, паттерны по дням недели
- **Исследования** — статистический движок корреляций + ИИ-объяснение (см. «Подходы»)
- **Эксперименты n=1** — активная проверка гипотезы (что меняешь / за чем следишь),
  до/после с размером эффекта (Cohen's d); ИИ предлагает эксперименты по твоему
  **реальному поведению** (тайминг кофе, поздняя еда, время отбоя/подъёма, активность)
- **Цели** — цель по метрике, прогресс-кольца, ИИ-рекомендации

### Настройки
- Язык RU / UK / EN; Telegram (привязка, отчёты, вечерний вопрос); Google Calendar /
  cal.beskarstaff; синк среды; ИИ-расходы (бюджет токенов); автосинк (shadow/live);
  экспорт данных (JSON + CSV)

### Чат с ИИ
Плавающая кнопка на любом экране. Период 2/4/12 недель. Полный контекст здоровья (ниже).

## Подходы и методы

Чем Tonus отличается от «ещё одного дашборда» — он не показывает абсолютные нормы,
а ищет закономерности в **твоих личных данных** и подаёт их честно.

**Статистика (движок `research.ts`, всё считается на клиенте):**
- **Корреляции Пирсона** — метрика↔метрика, проблема↔метрика, **среда↔метрика**.
  Порог |r| ≥ 0.3, n ≥ 7 дней. Среда (температура, давление, световой день, AQI,
  пыльца) учитывается как **немодифицируемый** фактор (🌍) — её нельзя «улучшить целью»,
  только учитывать; корреляции среда×среда не считаются (шум).
- **Эффект событий (Cohen's d)** — для бинарных/счётных событий (кофе, алкоголь,
  стресс, тренировка, **поздняя еда после 21:00**, приём препарата) сравниваем дни
  «с событием / без» по метрике, лаг 0 и 1 день; порог эффекта d ≥ 0.5.
- **Эксперименты n=1** — baseline-период vs период эксперимента, дельта + Cohen's d;
  подача как наблюдение с оговорками, не доказательство.
- **Личные базовые линии** — `daily_scores` (норма HRV и сна) для «готовности дня»,
  алертов и нуджей вместо абсолютных порогов.

**Дизайн-принципы:**
- **Поведение → исход.** Эксперименты и подсказки строятся вокруг управляемых привычек
  (что человек может изменить), а не абстрактного «делай больше метрики Y».
- **Честность вывода.** Индикатор полноты данных снижает уверенность при пробелах;
  везде оговорки «наблюдение, не диагноз».
- **Немодифицируемые факторы** (среда) отделены от управляемых рычагов.

**ИИ (Gemini 2.5 Flash):** объясняет находки простым языком, OCR анализов, vision для
еды, отчёты, рекомендации целей. Контроль расходов: каждый вызов пишет токены в
`ai_usage`, есть бюджет и cost-guard; `thinkingBudget:0` для экономии.

## К чему имеет доступ ИИ

ИИ **не выдумывает данные** — отвечает только по переданному контексту. Что именно
видит ИИ зависит от функции:

| Функция | Контекст, который получает ИИ |
|---|---|
| **Чат** (`chat-health`, `telegram-bot`) | Сон по ночам с фазами, пульс/HRV, активность, SpO₂; события (кофе/алкоголь/стресс/поздняя еда/тренировка); препараты + история приёма; анализы с **референсными диапазонами и флагами вне нормы**; заметки дня; проблемы; волосы. Период 2/4/12 недель |
| **ИИ-анализ периода** (`analyze-health`) | Метрики и тренды за выбранный период + заметки дня |
| **Двухнедельный отчёт** (`biweekly-report`) | Сводка метрик; анализы и препараты — по настройке приватности |
| **Объяснение исследований/экспериментов** (`deep-research`) | Готовые находки движка (корреляции + эффекты событий), помеченные внешние факторы; результат эксперимента до/после |
| **Подсказки экспериментов** (`suggest-experiments`) | За 30 дней: метрики + тренды; **поведение** (кофе вкл. после 16:00, поздняя еда, алкоголь, тренировки, время отбоя/подъёма из `sleep_sessions`) с учётом таймзоны; **среда** (жара/AQI/пыльца) как контекст |
| **OCR анализов** (`extract-lab`) | Изображение/PDF анализа |
| **Еда по фото/тексту** (`classify-meal`, `telegram-bot`) | Фото блюда или текстовое описание |
| **Рекомендации целей** (`generate-recommendations`) | Метрика цели и текущий прогресс |

Доступ к БД у функций — через service-role, но строго по `user_id` пользователя.

## Telegram-бот

| Возможность | Описание |
|---|---|
| ИИ-чат | Любое сообщение → вопрос ассистенту с полным контекстом; ответ рендерится в Telegram-HTML (жирный/списки) |
| Естественный ввод | «принял финастерид», «пил кофе в 14:00», «съел макдак» → запись в базу; «сейчас» = текущий момент. Кофе в составе еды пишется отдельным событием `coffee` (для модели кофеина), из заметки еды убирается |
| Еда по фото/тексту | Фото блюда или текст → Gemini считает калории/БЖУ → дневник |
| Напоминания о препаратах | Пора принять ✅ · +1ч ⏰ · +2ч · Пропустить ⏭ |
| Вечерний вопрос | «как прошёл день» → ответ в заметку дня |
| Проактивные алерты | HRV↓>20%, пульс↑>10%, 3 ночи <6ч — раз в день, дедуп |
| Контекстные нудги коуча | Связывают поведение с исходом по личным базовым линиям; follow-up через пару дней |
| Утренняя сводка | Опциональный дайджест утром |
| Двухнедельный отчёт | Авто или по запросу `/report`, настройки приватности |
| **`/idea` · `/ideas`** | Личный «ящик идей» по проекту — `/idea текст` сохраняет, `/ideas` список. Не показывается на сайте |
| `/usage` · `/tokens` | Лимиты Claude · расход Gemini-токенов за месяц |
| `/status /sync /pause /resume` | Управление синхронизацией и уведомлениями |
| Напоминания о фото волос / анализах | Раз в 28 дней (волосы) / 90 дней (анализы) |
