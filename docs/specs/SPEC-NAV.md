# Tonus — ТЗ: навигация и информационная архитектура

Отдельная спека по структуре навигации. Цель — убрать нагромождение из 12 плоских вкладок и собрать их в осмысленные группы, удобные и на десктопе, и на телефоне.

---

## 0. Проблема

Сейчас в один ряд вынесено 12 равноправных вкладок: `Дашборд · Активность · Сон · Стресс · Пульс · Показатели · Инсайты · Препараты · Анализы · Цели · Проблемы · Волосы`. В одном ряду смешаны разные по смыслу сущности, глазу не за что зацепиться, и на телефоне это не помещается в нижнюю панель.

## 1. Принцип группировки

В приложении по сути три типа сущностей плюс дашборд:

- **Тело** — то, что часы пишут сами и пользователь смотрит (физиология).
- **Дневник** — то, что пользователь ведёт и загружает сам (записи).
- **Коуч** — то, что система выводит и куда ведёт (ИИ-слой).

12 вкладок раскладываются по этим корзинам → остаётся 4 пункта верхнего уровня.

## 2. Структура навигации

```
Дашборд
Тело                (физиология — смотришь)
  ├ Обзор           (бывшие «Показатели»)
  ├ Пульс
  ├ Сон
  ├ Активность
  └ Стресс
Дневник             (записи — ведёшь сам)
  ├ Препараты
  ├ Анализы
  └ Проблемы
       └ Волосы     (под-раздел Проблем, не отдельная вкладка)
Коуч                (ИИ — выводит и ведёт)
  ├ Инсайты
  └ Цели
```

Плюс **плавающий чат-ассистент** (фаза 5) — он не входит в навигацию, остаётся кнопкой справа внизу.

## 3. Нейминг

Принято — человечный вариант: **Дашборд · Тело · Дневник · Коуч**.
(Строгая альтернатива, если захочется: Дашборд · Метрики · Записи · Коуч.)
Чат-ассистент называется «ассистент» и отделён от раздела «Коуч», чтобы не путать постоянный чат и раздел инсайтов/целей.

## 4. Карта переноса (старое → новое)

| Было (плоская вкладка) | Стало |
|---|---|
| Дашборд | Дашборд (верхний уровень) |
| Показатели | Тело → Обзор |
| Пульс | Тело → Пульс |
| Сон | Тело → Сон |
| Активность | Тело → Активность |
| Стресс | Тело → Стресс |
| Препараты | Дневник → Препараты |
| Анализы | Дневник → Анализы |
| Проблемы | Дневник → Проблемы |
| Волосы | Дневник → Проблемы → Волосы (вложено) |
| Инсайты | Коуч → Инсайты |
| Цели | Коуч → Цели |

## 5. Поведение по устройствам

### Десктоп
- Верхняя панель: 4 пункта (Дашборд · Тело · Дневник · Коуч).
- Внутри группы — вторичная навигация: сегментированный переключатель или под-вкладки (например, в «Тело»: Обзор / Пульс / Сон / Активность / Стресс).

### Телефон (фаза 3, PWA)
- Нижняя панель из 4 иконок: **Дашборд · Тело · Дневник · Коуч**.
- Заход в группу открывает её под-разделы (drill-in), назад — к панели.
- Плавающая кнопка ассистента поверх.

## 6. Принцип «дашборд-первый»

Дашборд должен показывать главное со всех разделов, чтобы в большинстве дней внутрь групп заходить не нужно было. Тогда количество вкладок перестаёт давить: пользователь живёт на дашборде, а группы — для «копнуть глубже». Это снимает ощущение перегруженности лучше, чем любое переименование.

## 7. Что не меняется

- Сам функционал разделов и их логика — прежние (фазы 1–9). Это рефактор **навигации и компоновки**, не переписывание фич.
- URL-адреса разделов желательно сохранить или сделать редиректы со старых на новые, чтобы не ломать закладки.

## 8. Этапы

- **N1:** ввести 4 группы верхнего уровня и разнести по ним существующие экраны (карта переноса, раздел 4).
- **N2:** вторичная навигация внутри групп (десктоп) + вложить «Волосы» в «Проблемы».
- **N3:** мобильная нижняя панель из 4 иконок (drill-in).
- **N4:** усилить дашборд как сводку по всем разделам.

## 9. Принятые решения

1. 4 группы верхнего уровня: Дашборд · Тело · Дневник · Коуч. **Решено: да.**
2. «Волосы» — под-раздел «Проблем», не отдельная вкладка. **Решено: да.**
3. Чат-ассистент — плавающая кнопка, вне навигации. **Решено: да.**
4. Мобильная нижняя панель — те же 4 пункта. **Решено: да.**
