# Tonus — ТЗ: редизайн экрана «Эксперименты»

## Цель
Переработать вид экрана `ExperimentsScreen` (вкладка Коуч → Эксперименты): сейчас
правая панель почти пустая (заголовок, один чип, кнопка в пустоте). Сделать
насыщенную, читаемую карточку результата; данные/edge-функции не трогаем.

## Контекст
- [src/components/research/ExperimentsScreen.tsx](../../../src/components/research/ExperimentsScreen.tsx) —
  двухколоночный layout (список слева, деталь справа). `computeResult` считает
  до/во время/дельта/Cohen d на клиенте.
- Бэкенд (таблица `experiments`, `suggest-experiments`, `deep-research`) — без изменений.

## Что меняется (только фронт + CSS)

1. **Статус-бейдж** в шапке детали: «Завершён» / «Идёт» / «Отменён» /
   «Запланирован» (по `status` + датам).
2. **Блок «До → Во время → Изменение»** — три карточки; карточка «Изменение»
   тонируется зелёным/красным/нейтральным по знаку и `betterHigh`.
3. **Шкала размера эффекта**: `d`, словесная метка (нет/слабый/средний/сильный)
   и 4-сегментная полоска.
4. **Мета чипами**: метрика (иконка), «Базовый: N дн», диапазон дат.
5. **Разбор ИИ** в карточке с иконкой; кнопка «Объяснить результат (ИИ)», пока
   нет разбора (логика `handleAI` без изменений).
6. **Идущий / без данных**: вместо пустоты — прогресс «День X из N. Результаты
   появятся после завершения.» (для активного, идущего сейчас) или
   «Недостаточно данных для сравнения.» (завершён, но мало точек).
7. **Список слева**: компактные карточки со статусом и мини-дельтой (+22% /
   Идёт / —) для беглого сканирования.

## Архитектура компонента
- Хелперы: `expStatusInfo(exp)` → `{ kind, label }`; `daysBetween(a,b)`.
- `ResultBlock` переписан под 3-карточный hero + шкала эффекта.
- `ProgressBlock` — прогресс для идущего эксперимента.
- Цвета — токены Tonus (`--green/--red/--accent/--surface/--surface2/--border`).
- Новые строки — в `translations.ts` (ru/uk/en), `t('День {d} из {n}', {d,n})`.

## Тестирование
- Сборка (`tsc -b && vite build`), lint без новых ошибок.
- Smoke: `npm test` зелёный (юнитов на компонент нет — node-env).
- Визуально — через прод после деплоя.

## Вне рамок (YAGNI)
- Изменения схемы/логики расчёта, edge-функций, формы создания.
- Графики/спарклайны динамики по дням (можно отдельной итерацией).
