# Лендинг Tonus 2.0 — дизайн-спека

Дата: 2026-07-04. Статус: одобрено пользователем (брейншторм в сессии Claude Code).

## Цель

Пересобрать лендинг так, чтобы он выглядел современно (референс — Linear/Vercel),
демонстрировал продукт живым демо вместо мокапов и вёл посетителя по истории
«данные → инсайт → действие». Анимации — заметные, но не перегруженные:
одна главная анимация на секцию, остальное — микро-детали.

Решения, принятые на брейншторме:

- Стиль: **Linear/Vercel** — тёмный, строгий, стекло/свечения/глубина.
- Анимации: **Motion (motion/react)** в landing-чанке через `LazyMotion`.
- Центр демонстрации: **живой мини-дашборд** на фикстурных данных, не мокап.
- Подход: **пересборка** структуры (тексты и i18n переиспользуем).

## Визуальный язык

- Фон: глубокий тёмный (текущий `--bg`), поверх — едва заметная сетка
  (CSS `background-image: linear-gradient`, opacity ≤ 0.04) и два радиальных
  свечения за hero (синий `--accent` и фиолетовый), которые медленно «дышат»
  (scale/opacity, цикл ~12 с, только transform/opacity).
- Карточки-«стекло»: `background: color-mix(in srgb, var(--surface) 72%, transparent)`,
  `backdrop-filter: blur(12px)`, граница 1px `color-mix(... var(--border) 60%)`,
  на ховере — свечение границы (`box-shadow` с цветом акцента) и лёгкий подъём.
- Заголовок hero: ключевая фраза с градиентом (accent → #9f7cff),
  `background-clip: text`.
- Токены не меняем: палитра, радиусы и шрифт — те же, что в приложении,
  лендинг и продукт выглядят одной системой. Светлая тема лендинга не
  поддерживается (лендинг всегда тёмный, как сейчас).

## Структура страницы

### 0. Topbar

Sticky, прозрачный на верху страницы; после скролла ~10px — blur-подложка и
нижняя граница (появление через Motion `useScroll`). Содержимое как сейчас:
логотип, язык, «Войти», «Попробовать».

### 1. Hero + живой мини-дашборд

- Сетка 1.05fr / 0.95fr (на мобилке — колонка), как сейчас.
- Заголовок: пословный stagger fade-up (Motion `staggerChildren` ~0.04s).
  Подзаголовок и кнопки — следом одним блоком.
- Кнопки: «Попробовать» (primary) и «Посмотреть демо» (ghost) — уже существуют.
- Справа — **`LiveDemoPanel`** (новый компонент):
  - Данные: `makeDemoDaily()` из `src/lib/demoFixture.ts`; готовность считается
    реальным `computeDailyScores` из `src/lib/scores.ts`.
  - Табы: Готовность / Сон / Пульс / Инсайты. Переключение — spring
    (Motion `layout` для подчёркивания активного таба, `AnimatePresence` для
    контента, direction-aware slide).
  - Содержимое табов:
    - Готовность: кольцо-скор (SVG, анимированный stroke-dashoffset) + 3 полосы
      (восстановление/пульс/сон) — как в приложении.
    - Сон: стековый BarChart (recharts) за 14 дней.
    - Пульс: LineChart resting HR + max за 14 дней.
    - Инсайты: 2–3 карточки инсайтов (статичные тексты из текущего
      InsightsBlock: кофе → сон, поздняя еда → HRV, стресс → пульс).
  - Под панелью — подпись «Это живые данные демо — открой полное демо» со
    ссылкой, вызывающей `enableDemo()` (уже реализовано).
  - Загрузка: `React.lazy` + IntersectionObserver/idle — панель монтируется
    после первой отрисовки hero; до этого — скелет той же геометрии
    (fixed aspect-ratio, без layout shift). LCP остаётся текстом заголовка.
  - recharts приходит из уже существующих shared-чанков приложения
    (vite разрулит), в критический путь лендинга не попадает.

### 2. Лента доверия

Тонкая строка из 4 пунктов: Apple Watch (авто-синк) · Telegram-бот ·
Gemini AI · «Данные твои — экспорт в один клик». Stagger fade-in
(`viewport={{ once: true }}`). Без каруселей и логотипов-марки.

### 3. «Как это работает» — 3 шага

- Десктоп: слева колонка шагов (текст), справа sticky-панель с визуальной
  сценой. При скролле активный шаг подсвечивается, сцена в панели меняется
  через `AnimatePresence` (fade + slide, ~0.45 с):
  1. **Синк сам** — иконка часов, поток точек в карточку приложения
    (упрощённая версия текущей сцены flow из HeroShowcase).
  2. **AI находит связи** — граф-паутинка (переиспользуем идею insights-web:
    узлы + линии, линии дорисовываются) и одна карточка-инсайт.
  3. **Проверяешь экспериментом** — таймлайн A/B и результат «+12% глубокий сон»
    с каунтером (переиспользуем текущий ExperimentsBlock-визуал).
- Активация шага: `useInView` на текстовых блоках (порог ~0.5).
- Мобилка (< 860px): без sticky — три обычные карточки «текст + визуал».

### 4. AI-чат

Сцена-переписка, запускается один раз при появлении в вьюпорте:

1. Вопрос пользователя (справа) — slide-in.
2. Typing-индикатор (3 точки, ~1 с).
3. Ответ ИИ — печатается посимвольно (~20 мс/символ, отключается при
   reduced motion — тогда просто fade-in): «По твоим данным: сон в среднем
   6.2 ч, поздний кофе 4 дня из 7 → попробуй сдвинуть кофе на утро».
4. Второй обмен — про анализы: «Ферритин ниже нормы — вижу связь с твоей
   усталостью по заметкам» (демонстрирует, что ИИ видит и лабораторию).

Тексты — текущие из ChatBlock + один новый обмен. Под сценой — подпись
«ИИ отвечает по твоим данным, а не из интернета».

### 5. Telegram

Новая секция (бота на текущем лендинге нет вообще, а это уникальная фича):

- CSS-мокап телефона (рамка, скруглённый экран), внутри — сообщения бота,
  всплывающие stagger'ом при появлении секции:
  - напоминание: «💊 Магний — пора принять» с кнопкой «✓ Принял»,
  - быстрый лог: пользователь пишет «кофе», бот отвечает «☕ Записал в 14:20»,
  - кусок еженедельного отчёта (сон ↑, HRV ↑).
- Рядом текст: заголовок «Телеграм — пульт от твоего здоровья» + 3 буллета
  (напоминания, лог одной строкой, отчёты раз в 2 недели).

### 6. Фича-грид

8 стеклянных карточек: Препараты и лечение · Анализы · Питание · Цели ·
Эксперименты · Проблемы и симптомы · Экспорт данных · 3 языка.
Stagger-появление, на ховере — свечение границы. Без тилтов и 3D.

### 7. Финальный CTA + футер

Крупный блок с мягким градиентным свечением за ним: «Готов(а) попробовать?»,
кнопки «Попробовать» и «Посмотреть демо». Ниже — мини-футер: «Tonus © 2026»,
переключатель языка.

## Технические принципы

- **Motion**: `LazyMotion` + `domAnimation`, компоненты `m.*` — экономит
  ~15КБ против полного `motion`. Всё в landing-чанке (лендинг уже отдельный
  lazy-чанк после code-splitting'а).
- **Reduced motion**: обернуть лендинг в `MotionConfig reducedMotion="user"`;
  фоновые свечения и печатание текста дополнительно гейтить на
  `prefers-reduced-motion` (при reduce — статичный конечный кадр).
- **Перф-бюджет**: JS лендинга (критический путь, без ленивой демо-панели)
  ≤ 150КБ gzip; LCP — текст hero; никакого CLS (скелет панели с фиксированным
  aspect-ratio). Анимации только transform/opacity, reveal — `once: true`.
- **i18n**: все новые строки через `t()` + `translations.ts` (ru/uk/en).
- **Файлы**: `src/components/landing/` перестраивается:
  - `LandingScreen.tsx` — новый порядок секций;
  - `blocks/` — новые: `TrustStrip.tsx`, `HowItWorks.tsx`, `TelegramBlock.tsx`,
    `FinalCta.tsx`; переработанные: `HeroBlock.tsx`, `ChatBlock.tsx`,
    `FeatureGrid.tsx`;
  - `LiveDemoPanel.tsx` (+ его табы) — новый, лениво загружаемый;
  - удаляются: `HeroShowcase.tsx/.css/.test.ts`, `heroShowcase.logic.ts`,
    `MetricsBlock.tsx`, `InsightsBlock.tsx`, `ExperimentsBlock.tsx`
    (их визуальные идеи переезжают в HowItWorks/LiveDemoPanel);
  - `Landing.css` — новые стили (сетка фона, стекло, свечения).
- **Тесты**: по текущему паттерну (env node, без рендера) — экспорт компонентов
  + покрытие переводов всех новых строк; обновить `Landing.test.ts`,
  добавить тест логики LiveDemoPanel (выбор таба, подготовка данных).
  Тест HeroShowcase удаляется вместе с компонентом.
- **Гейтинг не трогаем**: `gating.ts`, AuthScreen, demo-режим — как есть.

## Вне скоупа

- Светлая тема лендинга, SEO/метатеги, аналитика, A/B-тесты.
- Изменения в приложении за авторизацией.
- Новые тексты-лонгриды: копирайт остаётся кратким, переиспользуем текущий.

## Критерии готовности

1. Лендинг собирается, 3 языка без «дыр» (нет русских строк при en/uk).
2. Живой мини-дашборд интерактивен (4 таба, реальные графики) и не влияет
   на LCP (панель лениво, скелет без CLS).
3. `prefers-reduced-motion: reduce` — страница полностью читаема без анимаций.
4. Мобилка 375px: все секции читаемы, sticky-сцена деградирует в карточки.
5. Тесты и линт зелёные (не хуже базовых 295 ошибок), бюджет чанка соблюдён.
