# Настройки в стиле mate

**Дата:** 2026-07-11 · **Статус:** draft — на ревью пользователю.
Референс — приложение mate (скриншоты пользователя от 2026-07-11).

## Мотивация

Сейчас настройки Tonus — один длинный экран из ~12 карточек вперемешку
(язык, Telegram, cal.com, AI-бюджет, импорт, авто-синк, расписание,
приватность, среда, устройство, экспорт, архив), а часть управления
(тема, язык, выход) живёт кнопками в шапке. В mate это организовано
компактнее: меню профиля в шапке + структурированные настройки.

## Что переносим из mate

### 1. Меню профиля в шапке (вместо россыпи кнопок)

Аватар/имя в правом углу открывает дропдаун:

- **Тема** → подменю с тремя карточками-превью (Светлая / Тёмная /
  Системная) — УЖЕ СДЕЛАНО отдельной кнопкой 2026-07-11; при внедрении
  меню профиля переезжает внутрь пунктом «Тема: <текущая>».
- **Настройки** → экран настроек.
- **Выйти** (акцент опасного действия, как в mate — красноватый).

Кнопки темы/шестерёнки/«Выйти» из шапки убираются; язык — пунктом меню
«Язык: <текущий>» с тем же подменю. Стрик и колокольчик остаются в шапке.

### 2. Экран настроек — разделы вместо простыни

Группировка существующих карточек в секции с заголовками (или вкладки
слева на десктопе, аккордеон на мобиле):

| Раздел | Карточки |
|---|---|
| Профиль | язык, тема (дублирует меню), выход |
| Данные | импорт, авто-синк Apple Health, устройство, экспорт |
| Интеграции | Telegram, cal.com, среда/локация |
| Тренировки | расписание тренировок |
| AI | бюджет и расход |
| Приватность | PIN |

Порядок внутри раздела — по частоте использования. «Архив секций»
(текущая механика скрытия) сохраняется и работает внутри разделов.

## Не делаем (пока)

- Аватарки/загрузку фото профиля — в Tonus нет профильных фото.
- Востальном экраны mate (подписки, сертификаты) не имеют аналогов.

## План внедрения

1. `ProfileMenu` в шапке (тема/язык/настройки/выход) — заменяет 4 кнопки.
2. Рефактор SettingsScreen: массив секций → рендер разделами; каждая
   существующая карточка получает `section`-тег. Без изменения логики карточек.
3. Мобильное меню упрощается: остаются только навигация и профиль-пункты.
