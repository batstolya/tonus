## 3. Оптимизация токенов ИИ

Анализ `ai_usage` показал: чат — 67% расхода, biweekly-report — 19.6%, deep-research — 8.7%.

### 3.1 Сокращение контекста (chat + healthContext)
- **Было:**
  - `healthContext.ts`: lab_results limit 60, intake_events 80, supplement_logs 100 (перечислялись по дням), детальные дни 7
  - `chat.ts`: сон по 14 ночей, HR-сэмплы 7 дней, вода включена в контекст
  - `chat-health`: `maxOutputTokens: 2048`
- **Стало:**
  - lab_results 60→20, intake_events 80→40 (вода исключена), supplement_logs сжат до «препарат: N/14 дн»
  - сон 14→7 ночей, HR 7→3 дня, вода исключена везде
  - `maxOutputTokens: 2048→600` (ответы чата редко длиннее 400 токенов)
  - Экономия ~35-40% на чате.

### 3.2 thinkingBudget — главная утечка
- **Было:** Gemini 2.5 Flash без `thinkingConfig.thinkingBudget:0` тратит токены на внутренние «размышления». 5 функций его не имели: `analyze-health`, `biweekly-report`, `deep-research`, `extract-lab`, `generate-recommendations`. Это объясняет высокую долю biweekly-report и deep-research.
- **Стало:** `thinkingBudget:0` добавлен во все 5. Плюс урезаны раздутые `maxOutputTokens` (biweekly 8192→4096, deep-research/recommendations 4096→2048).

## 4. Рефакторинг (код-ревью)

### 4.1 Централизация вызовов edge-функций
- **Было:** 12 мест повторяли один бойлерплейт — `getSession()` + `fetch()` + сборка заголовков с токеном. Половина не проверяла `res.ok` → при ошибке 500 код молча получал `undefined` (скрытый баг, в т.ч. в моём ExperimentsScreen).
- **Стало:** новый `lib/edgeFunctions.ts` с `callFunction(name, body)`:
  - собирает auth-заголовок, бросает чистую ошибку если не залогинен
  - проверяет `res.ok`, достаёт `{ error }`/`{ message }` из тела
  - типизирован через generics
  - класс `EdgeFunctionError` со статусом
- Мигрировано 9 мест: ExperimentsScreen, ResearchScreen, GoalsScreen, MealLogger, SettingsScreen (×2), chat.ts, coach.ts, labs.ts, aiAnalysis.ts.
- `sendChatMessage` оставлен кастомным (особая обработка 402 — превышение бюджета).
- Нетто: −43 строки.

### 4.2 Языковой переключатель
- **Было:** флаг в шапке циклически переключал RU→UK→EN по клику. Неочевидно.
- **Стало:** иконка глобуса 🌐 → дропдаун с тремя языками и галочкой на активном. Флаги только внутри.

### 4.3 Редизайн экрана Инсайтов
- **Было:** заголовки секций в КАПСЕ (`goals-section-title`), хитмап прижат влево, плоские квадратные бейджи.
- **Стало:** карточки в едином стиле приложения, нормальный регистр заголовков, пилюли-чипсы с цветовыми акцентами, хитмап на всю ширину, AI-инсайты с левым акцентным бордером.

### 4.4 Дубли переводов
- **Было:** параллельная работа агентов добавила дублирующиеся ключи (`Фото`, `Отмена`, `Изменение`) — билд падал с TS1117.
- **Стало:** дубли убраны, билд `tsc -b` чист.
