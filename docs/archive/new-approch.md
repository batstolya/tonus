Да, и это как раз стоит автоматизировать.

Если данные сейчас идут так:

Apple Health → экспорт ZIP → ноутбук → загрузка в веб-приложение

то есть несколько вариантов убрать ручные действия.

Вариант 1. Самый простой и бесплатный

Apple Health → Health Auto Export → Firebase/S3 → ваше веб-приложение

На iPhone ставится приложение Health Auto Export, которое автоматически выгружает новые данные из Apple Health в облако по расписанию.

Схема:

Apple Health
      ↓
Health Auto Export
      ↓
Firebase Storage / S3 / Google Drive
      ↓
Ваш Backend
      ↓
База данных
      ↓
Веб-приложение

Плюсы:

практически без кода на телефоне;
автоматическая синхронизация;
можно обновлять данные каждый час или даже чаще;
не нужен ручной экспорт архива.
Вариант 2. Профессиональный

Сделать своё iOS-приложение с HealthKit.

Схема:

Apple Health
      ↓
Ваше iOS приложение
      ↓
API
      ↓
Backend
      ↓
Web App

Плюсы:

данные приходят почти в реальном времени;
полный контроль;
можно получать сон, шаги, пульс, тренировки, HRV, калории и т.д.

Минус:

нужно писать iOS-приложение;
нельзя получить данные Apple Health напрямую из браузера или сервера без приложения-посредника.
Вариант 3. Через Shortcuts

Можно настроить автоматизацию в приложении Shortcuts:

Apple Health
    ↓
Shortcut
    ↓
POST запрос
    ↓
Ваш API

Но работает менее надёжно и гибко, чем Health Auto Export.

Для твоего случая (веб-приложение уже есть) я бы выбрал:

Apple Health → Health Auto Export → Firebase → Backend → Web App

Тогда пользователь один раз выдаёт разрешения на iPhone, и дальше сон, шаги, пульс, тренировки будут подтягиваться автоматически без ZIP-файлов и без ноутбука. Это обычно можно запустить за несколько часов разработки, а не за недели.
