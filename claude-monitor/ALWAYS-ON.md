# Монитор лимитов Claude — как держать его живым

`/usage` в боте показывает свежие данные только пока монитор работает.
Монитор обязан крутиться на устройстве с **домашним (жилым) IP** — Cloudflare
блокирует запросы к claude.ai с серверов/облака.

## Вариант 1. На этом Mac как фоновый сервис (закрытая крышка на зарядке)
```bash
cd claude-monitor
./install-service.sh
```
- автозапуск при логине, авто-рестарт при падении;
- `caffeinate` не даёт Mac уснуть **пока он на зарядке** — работает с закрытой
  крышкой (clamshell);
- логи: `tail -f data/monitor.log`.

⚠️ На батарее с закрытой крышкой Mac всё равно уснёт. Этот вариант = «ноут
закрыт, но воткнут в зарядку».

Снять сервис:
```bash
launchctl unload ~/Library/LaunchAgents/com.tonus.claude-monitor.plist
```

## Вариант 2. Всегда-включённое устройство (ноут выключен совсем)
Тот же контейнер на Raspberry Pi / домашнем сервере / NAS / старом компе —
любой 24/7 девайс с домашним интернетом:
```bash
cd claude-monitor
docker compose up -d   # restart: unless-stopped уже в compose
```
Перенеси папку `claude-monitor` (с `.env` и `browser-profile`) на устройство и
подними контейнер. Это единственный способ получать данные, когда сам ноут
выключен.

## Почему не в облаке
Облачные IP (AWS/GCP/Vercel/GitHub Actions) Cloudflare режет на стороне
claude.ai. Нужен жилой IP, поэтому — домашнее устройство.
